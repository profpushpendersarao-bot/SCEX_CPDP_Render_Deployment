Method and interpretation notes

  • Defective is currently defined as defect count greater than zero. Confirm this matches the target semantics in each uploaded dataset.
  • The Random Forest uses balanced class weights as a cost-sensitive baseline; it is not a fully specified economic cost model.
  • Feature intersection uses exact column-name matches. Different schemas require a documented feature-harmonization step.
  • Filename-based project detection is a convenience only. Check the inferred project labels shown in the results.
  • Use results as exploratory until you have audited data selection, duplicates, project mapping, and validation design.
  • Render's local filesystem may be ephemeral. Download your results after each run.
